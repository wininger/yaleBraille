# yaleBraille

An R package for data visualization for low-vision and blind end-users

## Installation

### From CRAN
install.packages("yaleBraille")

### Development version from GitHub
# install.packages("devtools")
devtools::install_github("wininger/yaleBraille")

## Loading the Package
library(yaleBraille)
